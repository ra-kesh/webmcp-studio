Use a restrained editorial hierarchy with one decisive display scale and calm
body copy. Build rhythm from an 8-pixel spacing base. Keep large areas of warm
paper visible, use ink for primary text, and reserve the clay accent for
navigation, key facts, or one geometric gesture per page.

Images should carry narrative information. Crop them deliberately, write useful
alternative text, and avoid decorative media when a shape can do the job.
Repeated text, paint, and data values should remain reusable Studio styles,
variables, fields, and bindings rather than flattened literals.
