Scope: Asset Library dialog, Studio image entry points, inspector replacement, visible async/error states, compact layout, and local reference patterns. This is a read-only code audit. Browser, dev server, and build were intentionally not run.

## State and copy contract

| State                  | Required visible copy/action                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Uploads empty          | “No uploads yet” and **Upload Images**. Supporting copy: “PNG, JPEG, WebP, GIF, or SVG. Up to 25 MB each.”                                                         |
| Search empty           | “No images match ‘{query}’” and **Clear Search**. Keep collection tabs and Upload available.                                                                       |
| Loading uploads        | Skeleton cards plus one polite “Loading uploads…” announcement.                                                                                                    |
| Repository unavailable | “Uploads could not be opened on this device.” **Retry**. If other collections still work, keep their tabs usable.                                                  |
| Quota warning          | “Local storage is almost full. {used} of {quota} used.” **Manage Uploads**.                                                                                        |
| Quota failure          | “This image could not be saved because local storage is full.” **Manage Uploads** and **Retry**.                                                                   |
| Decode failure         | “{name} could not be read as an image.” **Choose Another File** or **Remove From Queue**.                                                                          |
| Missing blob           | “File missing on this device.” **Locate Replacement** and **Remove Layer**. Never suggest reload as the only repair.                                               |
| Upload cancelled       | “Upload cancelled.” **Retry** or dismiss the queue item.                                                                                                           |
| Referenced delete      | “Used by {N} layers across {M} pages.” **Review Uses**, **Replace Uses**, and **Cancel**. Do not show an enabled destructive action until references are resolved. |

## Minimum browser journeys once the host is healthy

1. Desktop insert from Recent, Uploads, and Library; assert geometry, selection, one-step Undo, and reopen/reuse after reload.
2. Desktop replace from all three collections; assert exact geometry/property preservation and one-step Undo.
3. Multi-upload with one success, one corrupt file, one cancellation, and one retry; assert independent queue states and no orphan records.
4. Empty, search-empty, list failure/retry, quota warning/failure, thumbnail failure, and missing-blob repair.
5. Zero-reference delete, referenced delete blocked with exact counts/navigation, delete failure/retry, and Undo where offered.
6. Keyboard-only insert, replace, upload, retry, cancel, collection switching, search/clear, item menu, and close/focus return.
7. Compact 320 px and 200% zoom. Assert one scroll owner, safe-area spacing, 44 px actions, no forced software keyboard, and no horizontal overflow.
8. At least 200 uploads. Assert bounded open/search/scroll time and object URL cleanup after close.
